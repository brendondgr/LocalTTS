Using a remote GPU

Run LocalTTS on the GPU machine (it stays on its own 127.0.0.1:5040), then forward it here:

ssh -N -L 5041:127.0.0.1:5040 user@gpu-box

and use http://localhost:5041. Voices and saved files live on that machine; AI-Enhance still runs here.
